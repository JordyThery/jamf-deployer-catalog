# Microsoft Apps

Word, Excel, PowerPoint, Outlook, OneNote, OneDrive, Teams, Edge and Windows
App from the App Catalog, installed automatically on every managed Mac and
kept up to date by Jamf.

Because the App Catalog handles updates, Microsoft AutoUpdate is set to
manual checks, and Microsoft AutoUpdate and the Microsoft Update Assistant
are restricted from running.

Needs the Fleet Foundation block. When you also use the App Catalog block,
leave these apps out of it.
