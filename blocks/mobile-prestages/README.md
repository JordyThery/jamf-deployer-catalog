# iPad and iPhone PreStages

Two mobile PreStages for Automated Device Enrollment, named
`<prefix>PreStage - 1:1` and `<prefix>PreStage - Shared`. The Fleet
Foundation groups recognise devices by the PreStage they enrolled with, so
keep these names.

The PreStages attach to the tenant's Automated Device Enrollment instance
named in the **Automated Device Enrollment instance** setting: the tenant
needs its ADE token uploaded first.
