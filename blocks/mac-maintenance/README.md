# Mac Maintenance

- Inventory at **startup** and **once a week** at check-in.
- Self Service items to **Submit Inventory** and **Collect Logs**. Collect
  Logs gathers the Jamf and install logs into a folder on the user's desktop
  for support.

Needs the Fleet Foundation block. Self Service Maintenance offers a similar
"Update inventory" item; pick one of the two.
