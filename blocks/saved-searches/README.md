# Saved Searches

Advanced searches for the fleet groups, named `<prefix>Search - …`:

- Macs: all computers, All Managed, All 1:1, All Shared, Administrator
  Rights assigned, and Macs enrolled in the last day.
- iPads and iPhones: all devices, All Managed, All 1:1, All Shared, and
  Restrictions unassigned.

Needs the Fleet Foundation block.
